# 本地 AI 对话

右侧栏通过「题目大纲 / AI 对话」切换。只有一个文字对话，Enter 发送、Shift+Enter 换行；等待时可以停止。

聊天视图已迁为 Vue 3 + TypeScript 组件，使用本地 Vite 构建产物。页签、主题、侧栏调宽及后端接口沿用原实现；开发位置和构建步骤见[前端迁移计划](../design/archive/FRONTEND_MIGRATION.md)。本阶段仅迁移实现方式，不增加自动读题或工具调用。

桌面端可拖动侧栏左边缘调整宽度，大纲和 AI 共用调整后的宽度，当前浏览器会记住设置。宽度限于 220～600 像素，并为题目保留至少 320 像素；双击边缘恢复默认。分隔边缘支持 Tab 聚焦及方向键调整，Home / End 到达最小 / 最大宽度。窄屏（不超过 1100 像素）保持原有展开式侧栏，不提供拖宽操作。

复用设置 → AI 评分中的调用来源、模型、密钥及免费额度登录，沿用免费来源优先及自定义模型回退。聊天独立于「开启 AI 评分」和自动评分开关，不改变评分结果。调用会消耗对应来源的额度。

不会自动读取题目、答案、笔迹、图片、题库或文件，不提供工具调用。需要讨论的材料由用户粘贴。回复按纯文本显示。

对话仅存当前页面内存；切题及切换侧栏保留，刷新或关闭后清空，不写入练习历史。发送最近最多 16 轮上下文；超过 48,000 字时从最早完整轮次开始移除。单条用户消息最多 4,000 字，回复最多 24,000 字。不自动重试失败请求。

同源 `POST /api/ai/chat` 接受 `{ "messages": [{ "role": "user", "content": "你好" }] }`，返回 `{ "message": "回复" }`。消息须 user/assistant 交替并以 user 结束，禁止自定义 system、URL、模型、密钥。沿用宿主认证及 Origin 校验，已授权局域网页面也可使用；没有独立服务端会话或共享聊天记录。主机最多同时处理两次聊天，断开、停止或服务退出时取消上游调用。
