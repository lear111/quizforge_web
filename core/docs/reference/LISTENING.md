# 宿主悬浮听力

听力材料属于题库，播放器属于宿主，题型只处理题目、答案、评分及编辑。现有拓展无需新增播放器或升级 Extension API。新增配置保持题库格式1和包格式3；未配置的旧题库行为不变。本轮只接入Web，Hub和Android尚未同步。

## 文件和绑定

```text
question-banks/<分组>/<题库>/
  bank.json
  media/library.mp3
  media/lecture.mp3
  media/exam.mp3
```

在 `bank.json` 根增加可选 `listening`，在需要听力的题卡上增加宿主字段 `listening`（与 `data` 同层）：

```json
{
  "listening": {
    "materials": [
      {"id":"library","title":"图书馆通知","file":"media/library.mp3"},
      {"id":"lecture","title":"讲座通知","file":"media/lecture.mp3"},
      {"id":"exam","title":"整卷听力","file":"media/exam.mp3"}
    ],
    "examMaterialId":"exam"
  },
  "questions": [
    {"id":"q1","title":"第一题","listening":{"materialId":"library"},"data":{}},
    {"id":"q2","title":"同材料第二题","listening":{"materialId":"library"},"data":{}},
    {"id":"q3","title":"普通题","data":{}}
  ]
}
```

示例省略了题库和拓展必填字段，`data` 仍遵守所选拓展Schema。完整演示位于 `question-banks/基础题型/听力组件演示/`，配套拓展是 `extensions/基础题型/单选题/`。四题总分17，四项功能开关全开；音频和前两道听力题取自PR #19的示例材料，整卷音轨由两段材料合并。

- 最多32段材料，每段最多8MiB，总计最多32MiB，继续遵循 `.qbank` 的单文件/总量限制。支持MP3、WAV、OGG、M4A，具体编解码播放仍取决于浏览器。推荐MP3。
- ID为1–80位字母、数字、下划线或连字符；标题1–160字符。文件为题库 `media/` 下直接文件，不接受URL、目录穿越、符号链接或任意文件路径。
- 多题可绑定同一材料；不配置题卡 `listening` 表示普通题。考试使用 `examMaterialId` 指定的一条整卷音轨；没有配置整卷材料时考试不显示播放器。
- 本轮材料清单及题卡绑定在文件中配置，不提供音频上传/裁剪/换绑编辑器。已有题目编辑器仍能正常修改题干、选项、答案和解析，保存时保留宿主听力配置。

## 交互

练习：听力题出现共享播放器；同材料切题继续播放；普通题暂停并隐藏，返回可手动续播；不同材料保存当前页面进度并切换，默认不自动播放。可选本库的听力材料、播放/暂停、跳转±15秒、拖动进度和调节0.75–2倍速。

考试：手动开始播放整卷音轨后切题不打断，在普通题保留紧凑入口；播放器功能与练习一致，可暂停、切换本库材料、拖动进度、跳转±15秒和调节0.75–2倍速；不额外施加考试限制。交卷、返回练习或离开考试时停止播放；暂停音频不暂停宿主考试计时。

复用草稿工具栏的拖动机制：按住卡片或胶囊（进度条、菜单和调宽手柄除外）移动超过6px后收成小球，通过逐帧transform跟手移动；松手按方向和速度吸附到预览区边缘八个停靠点，以同款弹簧动画恢复原卡片/胶囊。轻点仍操作按钮，拖动不会误触播放或菜单；系统减少动态效果偏好下省去形变/回弹。范围限制在题目预览区。右下角只左右调节宽度，默认360px、最小300px、最大560px；空间不足时按预览区可用宽度收紧。高度由内容决定，文字与控件不缩放；双击恢复默认宽度。最小化继续播放，再展开恢复尺寸。位置/宽度保存在独立浏览器偏好中；播放进度只在当前页面内保留，刷新不恢复。

播放器在宿主覆盖层，不随题卡白板缩放，也不进入答题区导出图。编辑、历史和汇总视图隐藏并暂停播放器。本轮不新增历史音频播放，也不保存播放次数到作答数据。

## 读取与持久化

集合概览增加 `listening:{materials:[{id,title,revision}],examMaterialId?}`；题目概览增加可选 `listening:{materialId}`。不公开磁盘路径。`revision`由宿主按音频内容计算，仅用于缓存刷新；制作者不填写。

`GET /api/collections/{kind}/{id}/listening/{materialId}` 返回声明材料的音频二进制，使用既有认证和页面会话边界。浏览器通过已有同源请求函数携带认证头读取，再用短期Blob URL播放，不把令牌放URL，也不把音频Base64塞入题目JSON。最多缓存两段材料，切换/关闭丢弃过期响应、取消请求并释放URL。

普通练习的音频改动参与题目内容版本校验；不同题库目录的材料互不共享。导出复制题库目录，导入生成独立副本，重命名/移动题库不会改变内部音频相对路径。考试开始时把声明材料复制入该次考试目录，与题目及拓展一起冻结；原题库删除/音频替换或服务重启不影响这次考试。

## 验收

后端：`core/server/host/resources/listening.test.mjs`。前端生命周期/取消/模式/几何：`core/test/practice/listening.test.mjs`。另回归集合、HTTP、考试及导入导出。浏览器需覆盖同材料连续播放、普通题暂停、切材料、提交判分、草稿、拖动/缩放、考试及窄屏。自动检查不替代手机/平板真机听音和触摸验收。
