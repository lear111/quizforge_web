# 拓展制作与修改

一个独立拓展提供一个题型和一本只引用自身的样例题库；组合题的小问由该拓展管理。页面、规则和 HTTP 协议见 [API 文档](API.md)。

## 统一状态与目录

题库与拓展不区分开发版或正式版，不需要发布、复制版本或移除标记后才能使用、导出。拓展可在授权范围内原位修改；id/version 保留为作者元数据，不参与新包导入去重；API 声明仍用于协议检查。不同内容的同 UUID/版本拓展可安装在不同目录，精确路径决定使用哪个。见[导入导出约定](LIBRARY_PACKAGES.md)。

~~~text
extensions/<物理分组>/<题型目录>/
  manifest.json
  practice.html / practice.js / practice.css
  rules.js
  question.schema.json / answer.schema.json
  examples/bank.json
  editor.json / editor.*                 # 可选
~~~

Manifest 声明文件路径及协议能力，旧 ID/版本元数据可保留；不要求 UUID。界面名称取拓展目录名。文件路径相对于叶目录，禁止符号链接和越界。每个拓展仅提供一个题型，不支持 manifest.types、packageFormatVersion、绑定 typeId。分组为一层物理文件夹。普通界面禁止拓展和分组改名、移动、代码编辑；删除前检查题库引用。根平铺拓展只显示升级错误，正常加载要求上述物理分组。

## 绑定、样例与旧数据

新题库使用 {"path":"extensions/<分组>/<实际目录>"}，可逐题引用不同拓展。样例 ID 为 examples，绑定自身；样例同样使用准确的自身 {path}，不再由宿主按 ID/version 自动改绑。样例的答案和历史独立于普通题库；四项功能开关默认开启。

旧 {id,version}、{"development":"叶名"} 绑定和旧开发版集合入口已退役，返回明确的升级提示。普通加载要求完整 Manifest，忽略 development.json 补缺配置；静态资源须写在 manifest.assets。旧作答恢复、固定 SDK 与冻结历史解码仍保留；不自动迁移或清空个人状态。格式 4 包每次导入新增独立目录；格式 3 包先按严格规则自动升级；旧包格式 1/2 不支持。新建示例使用文件格式 2、独立永久 UUID 及顶层集中大纲，示例变化会改变 V2 审核摘要。

设置“显示拓展管理”只控制管理入口显示，不影响题库加载。源码变更会使缓存失效；受影响的当前作答重置前保存备份，旧历史仍使用冻结页面。更新前备份数据，修改答案结构时仍需自行设计兼容。

## 保存、评分与统一收尾

页面调用 QF.save 保存完整答案，onFlush 必须等待尚未发送的输入与图片保存，失败时保留输入并明确报错。即时大纲使用 API 1.3 answer-state，稳定小题 ID 必须与 outline 一致。

完成练习时，宿主提交已保存且已作答的未提交题目，复用 grade(data,answer)；不点击页面按钮，不自行判分。拓展需处理空答、部分作答和小题总分。已提交题目不重复评分，未作答题目零分。主观题可返回 pending；AI 失败可重试或人工评分，不能伪造零分。完成前仍先 flush 所有输入。

## 草稿与资源

练习页面响应可用宽度；新草稿固定760逻辑像素，题卡与笔迹共用坐标，手机只缩放或平移。已有草稿 layout 保持原值；设备视图变化不写入共享草稿。拓展不应按物理设备强制改变草稿布局。

背景由宿主提供：页面 `html`／`body` 保持透明，宿主在题卡周围铺当前外观主题的底色或图片；草稿模式下改为白板纸张，手机宽度（不超过 600px）下宿主把整个题目页面铺成白底。拓展用自己的实底卡片（如基础拓展的白色题卡）覆盖需要的区域；直接把文字画在透明背景上会被主题背景干扰，需要保证可读时请画实底卡片。API 1.4 可通过 QF.ui.appearance 及 QF.ui.onAppearanceChange 获取主题与透明度；具体题卡样式仍由拓展实现。

静态资源使用 manifest.assets；动态答案图片使用 QF.resources；富文本使用 [公共服务](RICHTEXT_SERVICE.md)。

## 验证与交付

按 [题库制作技能](../../../skills/quizforge-bank-builder/SKILL.md) 验证结构、资源、作答恢复、提交、评分、编辑、历史、草稿与手机。结构校验或原型展示不等于功能验收。未实现接口明确失败。只允许按题库分组导出 .qbank，自动收集全部关联拓展到同名分组；导入校验格式、路径及内容，自动避让同名目录后成套新增。
