# 制作听力题

1. 打开 QuizForge，在“基础题型展示”中选择第 12–14 题；已有安装版升级后也可打开新增的“听力制作示例”题库。
2. 点击顶部的铅笔图标“编辑本题”。
3. 点击“导入本地音频”，选择 WAV、MP3、M4A、AAC、OGG 或 FLAC 文件。单段最长 3 分钟，原文件不超过 32 MiB。
4. 应用在本机浏览器中将音频压缩为 16 kHz、40 kbps、单声道 MP3。转换时显示进度，可以取消；原文件不会修改。
5. 试听音频，填写音频标题，编辑题干、选项、正确答案、答案解析和分值，然后点击“保存本题”。
6. 保存后可以切题、刷新或关闭再打开，导入的音频仍随题目保留。音频也会随题库导出和历史快照保留，不需要另外复制素材文件。

播放器支持播放/暂停、0.75–2 倍速下拉选择、前后 15 秒和拖动进度。每次打开播放器默认 1 倍速，点击倒三角展开列表，选定后自动收起并显示所选倍速。所有题目均不限播放次数；旧题目中保存的“两次”限制已经忽略。

导入的压缩音频最多 1 MiB，编码器只在作者页加载。浏览器不支持的文件会提示错误，原有题目和音频保持不变。使用新版 Edge 或 Chrome 可获得完整的本地音频转换能力。

安装版与解压版使用各自的数据目录。升级后的安装版会保留原有数据；桌面完整解压版的数据保存在自己的应用文件夹内。退出应用后再备份整个数据目录，才能同时保留题库、作答和历史。
