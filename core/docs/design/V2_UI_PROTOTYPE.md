# V2 界面原型说明

本文说明做题页**长什么样**。行为（能做什么、为什么）在 [总体设计](V2_ARCHITECTURE.md) 的决定表里，本文每一项都标出对应的 D 编号。

| 文件 | 内容 |
|---|---|
| [`prototype/workspace.dc.html`](prototype/workspace.dc.html) | 当前定稿的原型源码。颜色、尺寸、间距以它为准 |
| [`prototype/workspace-paper-theme.dc.html`](prototype/workspace-paper-theme.dc.html) | "答题卡"风格，留作以后的一套主题，现在不实现 |
| [在线画布](https://claude.ai/artifact/7Ga3br7JT2FSUSp4ELG9y7) | 可以点击操作的原型（负责人和 Claude 可见） |

原型源码是设计画布的格式：`{{ }}` 和 `<sc-for>`、`<sc-if>` 是原型自己的模板语法，脚本里的数据都是假的。实现时照搬**结构和样式数值**，不要照搬它的脚本。

## 2. 怎么更新

带界面的功能，在设计四步的第 ① 步里同时改原型（见 [工作流程](V2_WORKFLOW.md) 第 3 节）：

1. Claude 在在线画布上**改当前这一版**，不另起新稿；负责人看过、改过、确认。
2. 原型源码覆盖 `prototype/` 里的文件；本文的元素表加行或改行，版本记录加一行。和对应的决定一起合并。
3. Codex 实现后，把元素表里那一行的状态改为"已实现"。

元素表的"状态"只有四种：**已实现**、**本次接入**（当前任务要做）、**隐藏**（界面上不出现，注明哪一段做）、**参考**（原型里画了，但由拓展负责，宿主不实现）。

## 3. 布局

| 区域 | 桌面（宽于 900 像素） | 手机（900 像素及以下） |
|---|---|---|
| 题库栏 | 左侧，默认宽 256，可拖动右边缘调到 200–420，可收起 | 隐藏；顶栏"题库"按钮打开为左侧抽屉，带半透明遮罩 |
| 顶栏 | 中间区域顶部，高 56 | 换成手机顶栏：左"题库"、中题库名、右"大纲" |
| 题目区 | 中间，灰底，左右留出翻页按钮的位置 | 同左，两侧留白变窄，翻页按钮缩小 |
| 大纲栏 | 右侧，默认宽 244，可拖动左边缘调到 200–380，可收起 | 隐藏；顶栏"大纲"按钮打开为右侧抽屉 |

- 题库栏、顶栏、大纲栏三块底色相同（白），只有题目区是浅灰底。
- 三栏顶部同高（56），分隔线连成一条。
- 底部没有导航栏，翻页按钮在题目区两侧。
- 拖动边缘：鼠标移到侧栏内侧边缘出现 2 像素强调色细线，按住拖动；双击恢复默认宽度；键盘选中后左右方向键每次 16 像素。调过的宽度记在浏览器里，下次打开沿用。手机上侧栏是抽屉，宽 280，不能拖动。

## 6. 白板工具条的设计思路

白板属于宿主前端，题型拓展碰不到它。代码在 `core/web/draft/`：`whiteboard.js`（界面与交互）、`whiteboard-dock.js`（工具条停靠的几何计算，纯函数）、`whiteboard-model.js`（笔迹数据）、`whiteboard.css`。它从 V1 沿用，以后改动按这里的思路，不要换成别的做法。

**目标：像平板上的批注工具条，随手拿起、随手放下，不挡题目。**

| 设计 | 怎么做 | 为什么 |
|---|---|---|
| 浮动，不占版面 | 工具条浮在题目区上方，不占一行布局 | 草稿模式开关时题目不跳动 |
| 八个停靠位 | 3×3 网格去掉中心：四边中点、四个角。松手后吸附到最近的一个，按题目区的比例算距离 | 位置可预测；宽屏、竖屏都好用 |
| 边上展开，角上收起 | 停在边中点是展开的竖条（左右）或横条（上下）；停在角上收成一个圆球，显示当前工具，点按后沿左右边展开成竖条 | 需要时一点就开，不需要时只占一个圆点 |
| 拖动与点按分开 | 按住移动超过 6 像素才算拖动，否则算点按；任何位置都能按住拖，包括按钮上 | 不会点工具时误拖，也不用找专门的拖动把手 |
| 甩出去 | 松手时按最后 100 毫秒的速度预测 250 毫秒后的落点，吸附到那里 | 轻轻一甩就能送到对面，不用一路拖过去 |
| 弹簧动画 | 移动用略带回弹的弹簧；展开、收起的形状变化不回弹 | 移动有手感；形状回弹看起来像坏了 |
| 让开障碍 | 两侧翻页按钮是障碍物：停在那条边上的工具条向内让开；角上的圆球沿边滑开 | 不挡翻页 |
| 弹出框朝向页面 | 颜色、设置等弹出框开在工具条朝向题目的一侧，并限制在题目区内 | 不会弹到屏幕外 |
| 记住位置 | 停靠位存在浏览器（`localStorage`），每台设备各自记 | 位置是个人习惯，不进题库 |
| 键盘可用 | Alt + 方向键在八个位置间移动（跳过中心）；V/H 移动、P 画笔、E 橡皮、S 框选；Ctrl/⌘ Z 撤销，加 Shift 重做；框选后 Delete 删除；Esc 取消 | 不用鼠标也能操作 |

**工具**

| 工具 | 行为 |
|---|---|
| 移动 | 点题目里的选项、输入框照常作答；按住其他位置拖动白板 |
| 画笔 | 右下角小圆点显示当前颜色；已选中时再点一次，打开颜色选择 |
| 整笔擦除 | 碰到哪一笔擦哪一笔 |
| 框选笔迹 | 框住若干笔，可复制、删除 |
| 撤销、重做 | 没有可撤销的步骤时变灰 |
| 白板设置 | 粗细、纸色、纸面（空白、方格、点阵）、仅笔书写（开启后手指只能移动，适合平板手写防误触）、清空本题笔迹（要确认，确认后仍可撤销） |
| 全屏 | 只在草稿模式下出现 |
