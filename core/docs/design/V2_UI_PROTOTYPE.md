## 2. 怎么更新

带界面的功能，在设计四步的第 ① 步里同时改原型（见 [工作流程](V2_WORKFLOW.md) 第 3 节）：

1. 在**当前第 3 版独立 HTML** 上修改并通过文件侧边预览确认；不另起一套脱节的新原型。负责人看过、试用、确认后才算定稿。
2. 把确认后的 HTML 更新到 `prototype/quizforge-v2-mobile-overlay-bottom-nav-animated.html`，并同步本文的布局、动效、元素表和版本记录；行为决策同步到总体设计。
3. Codex 实现后，用真实 V2 页面与定稿 HTML 对照验收；只有功能代码、测试与界面一致时才把元素表中的状态改为“已实现”。

元素表的"状态"只有四种：**已实现**、**本次接入**（当前任务要做）、**隐藏**（界面上不出现，注明哪一段做）、**参考**（原型里画了，但由拓展负责，宿主不实现）。

## 3. 布局

| 区域 | 桌面（宽于 900 像素） | 手机（900 像素及以下） |
|---|---|---|
| 题库栏 | 左侧，默认宽 256，可拖动右边缘调到 200–420，可收起 | 默认隐藏；点击顶栏左侧按钮后，宽 280 的题库抽屉从**屏幕左侧覆盖整个视口（包括顶栏）**滑出，带遮罩 |
| 顶栏 | 中间区域顶部，高 56 | 沿用单行顶栏（56 高）：左侧题库栏开关、题库信息、草稿按钮、右侧大纲开关；不额外叠加一条手机标题栏 |
| 题目区 | 中间，灰底，左右留出翻页按钮的位置 | 601–900px 两侧翻页按钮缩小；≤600px 改为**底部独立翻页操作带**，内容区预留底栏空间 |
| 大纲栏 | 右侧，默认宽 244，可拖动左边缘调到 200–380，可收起 | 默认隐藏；点击顶栏右侧按钮后，宽 280 的大纲抽屉从**屏幕右侧覆盖整个视口（包括顶栏）**滑出，带遮罩 |

- 题库栏、顶栏、大纲栏三块底色相同（白），只有题目区是浅灰底。
- 三栏顶部同高（56），分隔线连成一条。
- **桌面与 601–900px** 没有底部导航栏，翻页按钮在题目区两侧；**≤600px** 使用独立底部操作带（高 76px 加安全区域），上一题、下一题按钮分别靠左右两端（48×52），不叠压在题目卡片上（D64）。
- 拖动边缘：鼠标移到侧栏内侧边缘出现 2 像素强调色细线，按住拖动；双击恢复默认宽度；键盘选中后左右方向键每次 16 像素。调过的宽度记在浏览器里，下次打开沿用。移动端（≤900px）的侧栏为固定宽 280 的覆盖式抽屉，不能拖动。

### 3.1 展开/关闭动效（D64，I② 已审查合并，待负责人试用）

| 交互 | 定稿表现 | 时间与缓动 |
|---|---|---|
| 题库分组 → 题库文件列表 | 内容区域向下滑动展开，收起时原路回缩；同时淡入/淡出，避免瞬时跳变 | 高度 300ms、透明度 220ms；`cubic-bezier(.22,1,.36,1)` |
| 桌面题库栏与大纲栏 | 从原宽度平滑缩至 0，或反向展开；收起后不占主内容宽度 | 宽度 320ms、透明度约 240ms；同一缓动 |
| 移动端题库/大纲抽屉（≤900px） | 左栏自左向右、右栏自右向左滑入；收起时反向移出；同时全屏半透明遮罩淡入/淡出 | 抽屉 340ms、遮罩 280ms；抽屉同一缓动 |

- 同一时刻只保持一个移动端抽屉打开；点击遮罩收起。避免使用 `display:none` 直接切断过渡，动画完成后隐藏/不可交互。
- 对设置了 `prefers-reduced-motion: reduce` 的用户关闭过渡动画。
- 第 3 版独立 HTML 使用模拟题库与题型，仅作为视觉和交互参考；I② 已在 Vue 宿主实现本节布局与动效；原型中的考试、设置等隐藏项仍未接入。

## 6. 白板工具条的设计思路

白板属于宿主前端，题型拓展碰不到它。代码在 `core/web/draft/`：`whiteboard.js`（界面与交互）、`whiteboard-dock.js`（工具条停靠的几何计算，纯函数）、`whiteboard-model.js`（笔迹数据）、`whiteboard.css`。它从 V1 沿用，以后改动按这里的思路，不要换成别的做法。

**目标：像平板上的批注工具条，随手拿起、随手放下，不挡题目。**

| 设计 | 怎么做 | 为什么 |
|---|---|---|
| 浮动，不占版面 | 工具条浮在题目区上方，不占一行布局 | 草稿模式开关时题目不跳动 |
| 八个停靠位 | 3×3 网格去掉中心：四边中点、四个角。松手后吸附到最近的一个，按题目区的比例算距离 | 位置可预测；宽屏、竖屏都好用 |
| 边上展开，角上收起 | 停在边中点是展开的竖条（左右）或横条（上下）；停在角上收成一个圆球，显示当前工具，点按后沿左右边展开成竖条 | 需要时一点就开，不需要时只占一个圆点 |
| 拖动与点按分开 | 按住移动超过 6 像素才算拖动，否则算点按；任何位置都能按住拖，包括按钮上 | 不会点工具时误拖，也不用找专门的拖动把手 |
| 甩出去 | 松手时按最后 100 毫秒的速度预测 250 毫秒后的落点，吸附到那里 | 轻轻一甩就能送到对面，不用一路拖过去 |
| 弹簧动画 | 移动用略带回弹的弹簧；展开、收起的形状变化不回弹 | 移动有手感；形状回弹看起来像坏了 |
| 让开障碍 | 两侧翻页按钮是障碍物：停在那条边上的工具条向内让开；角上的圆球沿边滑开 | 不挡翻页 |
| 弹出框朝向页面 | 颜色、设置等弹出框开在工具条朝向题目的一侧，并限制在题目区内 | 不会弹到屏幕外 |

| 键盘可用 | Alt + 方向键在八个位置间移动（跳过中心）；V/H 移动、P 画笔、E 橡皮、S 框选；Ctrl/⌘ Z 撤销，加 Shift 重做；框选后 Delete 删除；Esc 取消 | 不用鼠标也能操作 |
