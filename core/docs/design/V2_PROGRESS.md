## 第 1 段

**说明**：做完后，负责人启动 v2，能看到题库列表，打开一个题库看到大纲，做一道单选题，提交后看到分数。不包含：多选和判断、草稿自动保存、白板、重做、历史、考试。

**已完成**
- 后端只读部分（#60）：题库列表、大纲、单题读取、素材与听力、题型文件。提交前的响应不含答案。

**还要做**
- 后端：保存作答、提交锁定并返回答案、接收分数（高风险，需审查）
- 前端：Vue 入口、题库列表、大纲、题型页面容器
- 评分环境：真实 Chrome 桌面/手机尺寸可行性已验证；组件已实现并独立测试，待高风险审查后接入 Vue。它尚未接到日常作答页面。
- 单选题迁移到 v2，附一个 v2 示例题库

**实测速度**：浏览器操作尚未测量。下表仅为 #60 后端回环接口中位数，不包含界面显示与可交互时间。

| 操作 | 耗时 |
|---|---|
| 启动到可用 | 0.43–0.46 秒 |
| 首次打开题库（20 题 / 200 题） | 0.11 / 0.16 秒 |
| 再次打开题库（20 题 / 200 题） | 0.05 / 0.10 秒 |
| 读取一道题 | 约 4 毫秒 |

**需要负责人决定的事**：无。负责人已确认本段先按文件夹路径区分题库；改名或移动后按新题库处理，旧进度保留但不自动接回。作答文件上限沿用 32 MiB，写入失败保留原记录；待审查者记入总体设计决定表后用于保存实现。
