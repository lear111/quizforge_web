# K：限时考试、交卷与归档

**状态：已审查通过（Review #5922271705），PR [#186](https://github.com/lear111/quizforge_web/pull/186) 已 squash 合并到 `v2`，提交 `009f91f`；最终 CI 五项全绿；负责人已试用验收通过。**

用户可在题库内开始限时考试，切去其他题库再回来继续；交卷后使用现有批量评分，成绩汇总可将本轮归档并回到原练习。历史列表标记考试并显示用时。实现依据：[D24、D49–D52](../V2_ARCHITECTURE.md)、[接口](../V2_API_AND_STATE.md)、[存储结构](../V2_DATA_STRUCTURES.md)。

- **隔离与并发：** 练习和考试共用状态与笔迹仓储，以受检的 `exam/state.json` 选择考试作用域。开始考试不清空练习；开始和归档分别生成新的快照代际，旧标签页的快照不能写入新轮次。D27 内容失效仍然生效，清空失效作答并退出考试。状态文件损坏时保留原文件并报错，不静默回到练习。
- **时间与权限：** 持久化起止时间，概览返回服务器时间，界面使用经过校准的单调时钟计时。到点停止接收新答案输入，后端给在途答案 5 秒宽限；区外白板仍可写。交卷前宿主与后端同时阻止单题提交、重做；解析、结果以及只由解析引用的素材不泄露，拓展协议和评分沙箱保持原样。
- **交卷与恢复：** 手动提前交卷需要确认；当前题库到期或重开过期考试，宿主在现有保存队列排空后调用 `finish`，同一轮不循环自动请求。失败保留考试并可重试；若服务端已经锁定，则使用同一快照恢复结果，不重复锁定。未作答计 0，待评分可在重开后补评。历史用时按 D52 计算为实际交卷时间减开始时间，因此离线到期后补交的间隔也包括在内。
- **归档事务：** 复用 `restart.json` 的 prepared/committed、回滚及上一次回执。考试归档先完整准备历史副本，再移动当前 `exam/`；写入失败或提交前崩溃可恢复原考试，提交后重放不会产生第二轮历史。考试归档从不覆盖 `practice/`，也不新增历史索引。
