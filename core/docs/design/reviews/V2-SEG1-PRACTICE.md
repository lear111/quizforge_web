基于 `v2`，包含尚未合并的评分组件 #63；请先审 #63，再审本 PR 的增量。不更新 main，不使用真实数据；第 2 段未开始。

- **改动**：Vue 入口复用 LibraryList、OutlinePanel 和原有紫色视觉；每题独立 opaque iframe 收集答案，提交后才送入 #63 的 iframe/Worker 评分。`POST Q/submit` 原子保存并锁定后返回 solution；`PUT Q/result` 校验锁凭证、版本、分数、完整小题集合和精确十进制合计。答题及结果使用 `.qf-v2/state/`，COW、提交后冻结、原子替换、请求幂等；写盘失败不替换缓存。打开时只按题目记录与大纲条目清理活跃状态；素材、听力及拓展变化不清记录。历史仅预留索引。按设计 4.6，重新打开自动补评全部已锁定待评分题；提交成功立即换为锁定视图，评分失败仍不能改答案。
- **边界**：没有自动保存、白板、重做、历史、考试、AI、题库编辑或 V1 迁移。原有 V1 规则、标准答案、依赖与接口不改。未改变读取检查和遍历上限。32 MiB 与文件夹身份采用负责人已明确确认的决定，合并前请审查者补入总体设计决定表；不自行增加 D 编号。HTTP 沿用严格 JSON 解析，持久化解析额外容纳状态封装层，不扩大作答请求的解析深度。
- **文件**：`server/host/v2/{state,server,snapshots}.js`；`frontend/src/v2/{App.vue,page.ts}`、入口与 UI 产物；`test/v2/{submit,page,readonly}.test.mjs`；`scripts/dev/probe-v2-practice.mjs`；根目录演示启动脚本及 `examples/v2/` 下的独立单选题、grade.js、示例题库；进度与贡献说明。
