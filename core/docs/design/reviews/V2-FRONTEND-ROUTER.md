**范围与行为。** #138 已审查合并（`39fb2ad`）；本 PR 基于该提交，目标 `v2`，等待审查，不自行合并。页面、作答与评分行为不变；按 D④ 把当前位置交给 Vue Router 5.5.1（`dependencies`，hash 模式），不要求后端支持前端路径。`#/` 为未打开题库；`#/banks/:bankId` 打开题库并替换为实际题号；`#/banks/:bankId/questions/:questionId` 为题目；`#/banks/:bankId/summary` 只显示现有的完成后最终得分。空题库允许省略题号；未完成的汇总地址回到题目；未知地址回空白页。删除 `quizforge.v2.last-bank` 的读写，以地址恢复刷新位置，切回题库仍使用现有会话内最近八库的位置。
