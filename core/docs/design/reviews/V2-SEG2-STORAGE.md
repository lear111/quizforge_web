## 改动与边界

- 新增 `server/host/v2/ink.js`：`.qf-v2/ink/<整体内容指纹>/<题号SHA256>.json`，独立 inkRevision、最近4条回执、32 MiB/文件、原子替换；不缓存笔迹正文。指纹目录让“只有笔迹、还没有 state.json”也可按 D27 清理。overview 的 hasInk 用文件名索引，表示存在保存记录（包括空白板），不读取正文；单题 GET 才读取。选项保存完全不读取/序列化/写入 ink；笔迹只替换本题文件，不改主文件或其他题。retry 先删本题笔迹再写主文件：后一写失败时答案保留、笔迹已删，可重试；D27 清理同样先删全笔迹再写主状态，不声称跨文件回滚。
- `state.js/snapshots.js/io.js/type-registry.js/server.js`：根 contentFingerprint 覆盖 bank.json 原始字节和已使用题型的文件内容（确定顺序，保留文件内容交换的检测），不含物理路径、题库素材、无关文件和 SDK；不一致清空全部活跃记录，historyIndex 不变，返回“题库或题型已变化，本轮作答已清空”；没有作答文件不创建。删除逐题指纹，锁凭证改带整体指纹。旧 V2 没有指纹时按变化清理，不做迁移。
- 删除 `position.js` 及位置接口。lastQuestionId 只随 draft/submit/retry 更新，result/ink/浏览不更新。`App.vue` 保留本窗口浏览位置与 V2 上次题库键；答案确认省略 ink，前端保留已知笔迹版本，ink 使用 expectedInkRevision，仍共用串行队列。普通作答暖读借用冻结缓存，不再重复解析文件路径；打开/刷新仍重新检查身份及字节，写盘仍检查路径。
- D29 缓存清点：opened LRU8，逐出同步释放 state.loaded/identities、ink 文件名索引、题型解析与 SDK 描述；带 snapshotId 访问逐出题库时从磁盘重开，同快照透明继续，变化走 D27/过期。FileCache 保持正文256条/32 MiB、摘要8192条/64 MiB。前端位置表8条；题型源码/SDK Promise 只属当前题库，切库/刷新/令牌变更/卸载清空并取消；评分槽60秒闲置删除、10秒超时销毁，卸载全释放；页面资源/对象URL随 iframe 销毁。JSON WeakMap 随对象回收，本次序列化局部键/数字备忘各最多1024项，调用后释放。没有新增跨库浏览器缓存。
- 文件清单另含 `platform/json.js`、UI构建产物、`test/v2/{drafts,position,readonly,submit,storage,json-fields,write-queue}.test.mjs`、三个测量脚本与白板浏览器检查脚本、接口速查/进度页。未改 V1 白板、评分/锁定/solution 发送边界、V1 标准答案、真实数据、日常服务、部署或安装包；④未开始。
