## 范围与兼容

- 迁入原公开基础展示库 3 单选、2 多选、2 判断，保留原题号 1/2/3/7/8/9/10、题干/选项/解析、公式/表格/图片和分值。多选完全匹配得满分，否则 0；判断 false 是有效作答。页面按 V2_EXTENSIONS 调用 changed/submit/retry，得分在页面内。使用已发布富文本 1.1.3 的 JS 和 CSS；不修改 SDK。生成脚本只处理这份公开展示，非通用转换器；简化 3 题移到测试夹具，原有忽略的演示记录目录不删除。
- D36：移除题型自带笔记及旧 `Q/draft`，答案由 `PUT Q/answer` 保存，锁后仍可独立保存白板。D37/D38：状态精确到小题，五种大纲颜色与说明；点选立即更新，锁定不变色，后端按满分判对，无法评分用警示色。
- D39：每题六个字段；共享 revision + submissionId 校验评分；答案和笔迹分别保存四条有序回执；主状态无历史索引。评分结果为 score/parts/message，区分待人工或 AI、无法评分、尚未上报（仅后者自动补评）。可识别的旧开发记录按内容变化清空，损坏记录保留；只有旧笔迹时按题清空。不改 v1 标准答案；新 V2 提交与笔迹向量仍逐字节检查，包括数字字面量。
- 题型内容地址与带 snapshotId 的 SDK/题目图片返回 private,max-age=31536000,immutable，并按访问令牌 Vary；SDK URL 带含 SDK 摘要的快照，开发题型 no-store；仅当实际响应字节的 SHA-256 与快照记录匹配时才标 immutable，外部替换后的新字节不会被旧 URL 缓存。解析专用素材即使锁后也 no-store（retry 不换快照，不能缓存绕过再次锁前检查）；错误/概览/单题/写入仍 no-store。原鉴权、网络隔离、锁前 solution 不可见、版本/FIFO/原子写入保证不变。
- 文件：examples/v2 的题库/三题型及启动入口；frontend/src/v2 的 App/page/source-cache/outline/grading/scoring、共享状态工具与产物；server/host/v2 的 io/state/ink/receipts/snapshots/server/type-registry；test/v2、测试夹具及 dev 下生成/浏览器/测量脚本；README、进度与接口速查。不做简答/答题区、历史/考试/听力、真实数据迁移、安装包或第 2.5 段清理。
