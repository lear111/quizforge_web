# 题型页面接口对齐（D35）

依据：[#83 审查“下一步”](https://github.com/lear111/quizforge_web/pull/83#issuecomment-6848344234) 与 [V2_EXTENSIONS.md](../../reference/V2_EXTENSIONS.md)。#83 已合并（4b18a59）；本 PR 涉及保存与沙箱通信，等审查，不自行合并。

## 改了什么／没有改什么

- 已有单选示例自己显示提交、重做、得分与反馈；宿主提供 `QF.page.submit/retry()`，校验来源、通道、题目代际、mode/can 及正在执行的操作。context 补 can/appearance；同一 iframe 完整重画，操作回复仍对应发起时的代际。自动测量内容高度，销毁时断开观察器并释放对象 URL。
- `changed({kind,answered})` 即时更新大纲，布尔或小题部分映射随 answer 持久化，忽略未知小题；形状检查的映射上限为 1000 键。小题分别显示已作答和评分结果。旧保存确认不回滚新输入的状态；首次草稿改变重做权限时，暂阻新输入并往返读取以排空旧消息，再重画，不在每次保存时重画。
- `PUT ink` 只确认 `{inkRevision,state}`，前端沿用本地笔迹；单题读取仍返回正文。同步 [接口与状态速查](../V2_API_AND_STATE.md) 与进度页。
- 不改评分器、锁凭证、内容指纹、回执/FIFO、版本号、保存时机、白板工具、沙箱网络/宿主隔离及 solution 可见条件。不改总体设计/题型接口原文；不做④原基础库迁移/浏览器资源缓存、历史、考试、听力、转换、旧代码删除或安装包。#83 的后续缓存与测量事项已记入进度。

## 文件与兼容

页面：`frontend/src/v2/{App.vue,page.ts,outline.ts}`、构建产物、已有单选示例；后端：`server/host/v2/{state.js,snapshots.js}`；共同元数据形状：`shared/v2/answered.*`。测试：`test/v2/{answered,page,drafts}.test.mjs`；真实浏览器脚本：新增 `probe-v2-page-contract.mjs`，其余三个既有脚本仅改按钮/结果所在页面的选择器。

answered 是可选字段，未上报时旧记录不补写；概览缺省 false/空映射，不从答案内容推测。锁后仅笔记/笔迹保存不改该字段，retry 清空。既有笔迹用例改为断言最小确认后再 GET 验证答案/锁/结果与笔迹，其余边界断言保留；标准答案不更新。
