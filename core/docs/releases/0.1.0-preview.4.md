# QuizForge 0.1.0-preview.4

Windows 10/11 x64 预览版。本次提供安装程序，程序内含 Node.js，用户无需安装 Node.js 或 Java。双击 `QuizForge-0.1.0-preview.4-win-x64-setup.exe` 安装，通过桌面或开始菜单快捷方式打开。

## 本版内容

- 答题区支持文字、手写、拍照、上传和粘贴图片，内容可自动增高；图片可双击选中、移动、等比例缩放及确认删除。手写使用宿主草稿图层，答题区内笔迹在练习模式继续显示。
- 用户中心支持登录 Hub 账号、查看免费 AI 余额及兑换；评分来源可选择免费额度、自定义模型或两者，保留各端的权限与数据边界。
- 用户中心新增“联系管理员”，无需登录 Hub，打开时读取管理员发布的公开内容，支持失败重试和关闭取消。本地 Web 沿用用户中心的宿主电脑访问限制。
- 新增“青屿”海岸插画主题，加深设置图标；保留原有主题和自定义背景偏好。
- 基础题型后台保存时仍可点击提交、重做，执行时等待必要的保存与组件写入，并防止重复提交；修复重做后的笔迹恢复及默认展示库的图片引用。
- 仅附带基础题型展示库和五个基础拓展；其他题库可通过应用中的“获取题库”下载。

## 升级与数据

安装新版前，先保存当前输入并从托盘退出旧程序。安装版的程序与数据分开，数据默认保存在 `%LOCALAPPDATA%/QuizForge`；升级和卸载保留题库、拓展、设置、作答和历史。基础内容只在首次初始化时复制，不覆盖用户修改，也不补回用户已删除的题库。

解压版或源码目录的数据不会自动搬入安装版。题库可通过 `.qbank` 导出、导入；需要迁移完整作答和历史时，先停服并备份完整数据目录。不要仅复制题库文件就删除原目录。题库包继续使用格式 3，格式 1、2 需要制作者升级。

## 验证范围

发布前检查覆盖自动回归及隔离安装、启动、快捷方式、文件关联、升级、卸载和数据保留。真实设备的触控笔、摄像头、输入法，以及真实账号授权和 AI 计费体验仍需使用者在对应设备上确认。具体检查结果与构建摘要见安装包旁的发布前检查记录；本说明不代表已经创建 GitHub Release。
