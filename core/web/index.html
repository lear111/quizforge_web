手机安装步骤
  1. Android：用 Chrome 扫码①下载证书，然后打开“设置 → 安全 → 加密与凭据 → 安装证书 → CA 证书”，选中下载的 QuizForge-LAN-CA.crt。不同品牌菜单名称略有差异，可在设置里搜索“CA 证书”。
  2. iPhone / iPad：用相机扫码①，在 Safari 中允许下载描述文件；到“设置 → 已下载描述文件”安装；再到“设置 → 通用 → 关于本机 → 证书信任设置”，为 QuizForge LAN Root CA 开启完全信任。
  3. 扫码②或手动打开 HTTPS 地址，输入连接密码。

根证书只装在你自己的设备上，不要发给别人。根证书私钥只保存在这台电脑的数据目录，任何地址都不会提供私钥。关闭局域网 HTTPS 会停止 HTTPS 端口；证书保留，再次开启无需重装。

此设置不会修改 Windows 防火墙。连接不上时，请允许 Node.js 的网络访问，或放行连接端口。
