# 简答题 1.3.0

要求 Extension API 1.2，并声明公共富文本 `advanced-v1` 能力；不绑定具体编辑器版本。题干、回答、参考答案、编辑页面和资源格式沿用 1.2.2。

提交答案保存初始 0 分。人工评分以 0.5 分为单位，拖动后自动保存；切题前等待最后一次评分保存，保存失败保留当前选择并允许重试。

AI 评分由宿主执行并自动应用有效结果，题卡保留评分、重试和重新评分按钮。是否在提交后自动调用 AI 由宿主设置控制；页面加载只恢复任务进度，不启动模型请求。历史页面只读。

在 `core/` 运行 `node scripts/build-short-answer-auto.mjs` 仅构建此新版本的规则文件。旧包和已冻结的历史页面保持原样；题库需要明确绑定 1.3.0 才会使用此版本。
