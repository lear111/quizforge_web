# 简答题 1.2.2

此版本精确使用公共富文本 SDK 1.1.2，提供调整后的编辑工具和图片拖拽宽度控件。题目、回答、AI 输入和人工评分继续使用原格式与接口；图片宽度使用已有的结构化 `width` 属性，不增加数据迁移。Manifest 显式声明 Extension API 1.0。题目只展示和编辑题干，题名作为宿主协议元数据由题干自动派生。旧版拓展和 SDK 保留原样，历史继续使用原有固定快照。

练习卡和题目编辑卡最大宽度均为 704px，正文外边距为桌面 28px、手机 20px；预览、内联编辑和高级编辑使用公共 SDK 的同一套正文样式和宽度。高级窗口继续使用当前编辑器实例，关闭时保留选择位置和撤销记录。

`prepareAiGrading(data, answer)` 将题干、已提交答案、参考答案和评分说明转换为协议版本 1 的文本/图片块。公式保留 LaTeX，表格保留行、列、表头与跨行跨列信息；图片只包含资源 `assetId`，不保存运行时 URL。排版属性不影响评分协议。建议以 0.5 分为步长，由宿主调用模型并保存任务；拓展不持有模型密钥。

作答提交后，点击 AI 评分获取建议。排队和运行状态通过宿主接口查询，失败后可以重试，也可以重新评分。建议不会自动写入成绩：用户可以调整分数，再确认 AI 评分；仍可直接手动评分。最终评分理由由服务端返回，历史页面只读。

页面加载只读取当前任务以恢复进度，切题或销毁时取消轮询并忽略过时请求。恢复正文不恢复撤销栈。

开发时在 `core/` 运行 `node scripts/build-short-answer-advanced.mjs`，只生成尚未发布的 1.2.2 `rules.js`，不重建旧拓展或公共 SDK。发布后修改组件必须使用新的版本号。

普通启动保留题库的精确版本绑定。保存作答并关闭服务后，显式运行根层 `Start-QuizForge-Web.cmd -UpgradeShortAnswer`，才将已知 1.0.0、1.1.0、1.2.0、1.2.1 简答题升级到本版；单拓展与混合题库均支持。只有 1.0.0／1.1.0 的旧独立题名会补入题干；1.2.0／1.2.1 的题目内容保持原值。

进行中的回答、评分、笔迹和旧历史保留；有未保存的简答编辑草稿时明确拒绝升级，先保存或取消编辑，原草稿不会覆盖。单拓展生成独立版本状态，已有目标状态时拒绝覆盖。题目级绑定沿用混合状态标识；进行中轮保留其它题型当前状态，已完成轮的全部答案转为草稿。用可恢复事务更新题库绑定和状态签名，升级前的题库与状态原字节保存在 `.state/upgrade-backups/`；旧进行中历史关闭后保留原题目、页面和评分，新版开启承接当前提交的新轮。已完成轮次仍冻结，原回答转为新一轮草稿。升级前仍建议备份整个产品目录；当前不是通用迁移工具。
