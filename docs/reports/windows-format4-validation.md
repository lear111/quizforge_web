## 实现范围

- 本地存储继续是 `question-banks/<组>/<题库>/bank.json` 或根层题库文件夹，分组一层；永久作者 UUID 与私有 `.instance.json` 练习身份分开。
- 原生 JavaScript 严格转换格式 3→4、文件 1→2，不要求用户安装 Python。Python 只用作差分参照。保留题目 data 的数值 token，包括负零、大整数、小数和指数原写法。
- 新建及另存为随机生成小写 UUIDv4；题目编辑、改名、集中大纲编辑、重新打包、导出、导入保持已经落盘的作者 UUID。另存为使用新 UUID 和独立练习身份。
- 集中大纲控制分组、显示范围与题序；隐藏题仍完整校验。考试和历史冻结目录，不从现有题库重新推导。编辑器提供集中大纲 JSON 与题目 ID 参照，保存检查修订冲突。
- 本地批量升级逐叶备份、暂存、验证、目录交换与回滚；一本失败不阻止其他，已升级跳过。备份 `.backups/qbank-format4/<时间-UUID>/original/`；报告同时保存在该次备份目录和可下载界面，不含题目正文或答案。
- 导入格式 3 在隔离暂存中自动转换并告知；导出仅格式 4，尚未落盘 UUID 的旧题库要求先升级。音频原字节 `media/`→`assets/`；图片支持安全文件名并按内容哈希索引。上传 128 MiB、展开 256 MiB、JSON 8 MiB、本地音频 32 MiB、图片 4 MiB；Windows 文件/Hub 导入入口一并提高上传限制。
- 网络 URL 原实现纳入同一 PR，转换/导入/导出/考试快照保留原字符串；匿名浏览器完整缓存 64 MiB，不经宿主下载代理。**未声称与 V2 v0.8 完全一致**，见 [核对矩阵](format4-network-audit.md)。

## 影响及保留问题

仓库自带基础题库和以下 5 个拓展示例已在隔离工作树升级；原开发目录及作者真实题库未迁移：

- `extensions/基础题型/单选题`
- `extensions/基础题型/多选题`
- `extensions/基础题型/判断题`
- `extensions/基础题型/简答题`
- `extensions/基础题型/简答题（答题区）`

这些示例变化会改变拓展审核摘要，V2 需要重新审核。其他用户执行批量升级时，以各次报告的 affectedExtensions 为准。拓展 manifest、规则、Schema、HTML、CSS 未因此改写。

包内 UUID 必须唯一：同一作者题库的多个导入副本放在同组再一起导出、或不同路径拓展示例 UUID 重复，会拒绝并报告位置；导出器不自行换 UUID。真实新题库可用“另存为新题库”，独立新拓展的示例身份由作者维护。

网络校验、进度显示、Python/V2 URL 支持差异见单独报告，按作者要求待审阅，不自行修改契约。没有远程联调、生产部署、安装包发布或 PR 合并。
