# 网络音频与 V2 v0.8 的逐项核对

参照：V2 `docs/listening-url@bdbced2fa0c217d605578fa67946d447c54cc745`，设计 06 第 4.2.1 节。核对原有未提交网络音频实现，纳入格式 4 PR；按作者要求，发现的契约差异只报告，不自行选择新的限制。以下均不访问远程音频服务。

| 规则 | 当前 Windows 实现 | 结果 |
| --- | --- | --- |
| `file` / `url` 恰好一个 | 加载及格式 3→4 / 格式 4 校验均检查字段存在性 | 一致 |
| HTTPS、无账号密码、无片段 | 宿主校验；播放器也检查这些项 | 一致 |
| 最长 2048 | 宿主原实现为 **4096**；浏览器没有独立长度上限 | **差异，待决定** |
| 原文等于 WHATWG 规范化结果 | 未检查相等；例如 `https://MEDIA.example.test:443/a.mp3` 被接受；存储保留原文，实际请求使用 `new URL(...).href` | **差异，待决定** |
| localhost / .localhost / .local / 单段主机名 | 宿主拒绝；还额外拒绝 `.internal` / `.lan` / `.home` | 额外限制 **待决定** |
| 私有、本机、链路本地、保留 IP 字面量 | 宿主拦截常见内网 IPv4、共享地址、组播及 IPv6 非 2000::/3；但仍接受 `192.0.2.1`、`198.51.100.1`、`203.0.113.1`、`2001:db8::1` 等文档保留地址 | **不完整，待决定** |
| 播放前浏览器重复完整地址校验 | 播放器只有 HTTPS / userinfo / 片段 / 空白控制字符检查；不重复主机与 IP 限制 | **差异，待决定** |
| 匿名请求 | GET、CORS、`credentials: omit`、`referrerPolicy: no-referrer`；仅发送 Accept，不调用有认证的宿主请求辅助函数 | 一致 |
| 无任意 URL 下载代理 | 宿主对网络材料的二进制入口返回 422；不 fetch，不解析 DNS | 一致 |
| 先完整缓存当前段，再播放；最多 64 MiB | 先检查 Content-Length，再流式计数；完成后生成 Blob 才交给播放器；缓存最多两段 | 一致 |
| 只接受音频响应 | 200 状态与既有音频 Content-Type 白名单；拒绝重定向和部分响应 | 满足核心要求；白名单比泛指音频类型更窄 |
| 下载进度 | 显示“正在读取听力材料…”；**无字节进度** | **差异，待决定** |
| 重试 / 关闭 / 切材料取消 | AbortController、超时、过期响应丢弃；重试重新读取 | 一致；最小化不等于关闭 |
| CORS 错误提示 | TypeError 提示检查网络和 CORS；浏览器无法准确区分断网和跨域拒绝 | 不宣称精确区分 |
| 导入 / 导出 / 考试快照保留 URL | 不下载、不改 JSON 字符串；URL 参与内容身份及播放器缓存键，网络材料不复制进快照 | 一致 |
| CSP | 只对宿主页增加 `connect-src https:`；题型 iframe 网络策略不变 | 一致 |

## V2 参考工具与文档之间的差异

上述 v0.8 分支只更新设计文档，`tools/qbank-upgrade/upgrade.py` 的 materials 白名单仍为 `id/title/file`，因此会拒绝 `url`。本 PR 按 v0.8 文档保留 URL，不能宣称含 URL 的合成包已与这个 Python 工具差分一致。普通本地音频包继续做差分；URL 的原样保留另做本机自动测试。V2 main `5f23e2f37d93d0bbafdac7af12c5e2d75b2d5603` 也尚未包含这个文档小节，不能据此声称 V2 main 已实现网络音频。

以上差异必须随 PR 一起审阅，不能将本次接入描述为与 v0.8 完全一致。无正式站、已部署测试站或真实外部音频验收。
